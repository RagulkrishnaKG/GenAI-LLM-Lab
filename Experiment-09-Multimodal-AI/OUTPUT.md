# Experiment 09 - Output

## Input
Place an image named `sample.jpg` in this folder.

Question:
```text
What is visible in the image?
```

## Sample Output
```text
Generated Caption: a dog running in the grass
Question: What is visible in the image?
Answer: dog
```

## Result
A multimodal AI application was implemented using a BLIP-based transformer model to process image information and generate a text caption and answer a question about the image.

> The exact caption and answer depend on the image used.
